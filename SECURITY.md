# Security Policy

## Supported Versions

Currently, only the latest release of Safivra is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for Safivra, especially as a personal financial management system. 

If you discover a security vulnerability within Safivra, please do **NOT** create a public GitHub issue.

Instead, please send an e-mail to our security team (or project maintainer). We will endeavor to respond to your report within 48 hours and release a patch as soon as possible.

### What to include in your report
- A description of the vulnerability.
- Steps to reproduce the vulnerability.
- Any potential impact on users.
- Your contact information for follow-up.

Thank you for helping keep Safivra secure!
